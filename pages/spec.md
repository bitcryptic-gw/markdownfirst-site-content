This page will point at the MDF 0.3.1 specification and the validator, and explain the two
things a site has to get right to claim conformance: markdown served at the same URL under
`Accept: text/markdown` with `Vary: Accept`, and an honest `/mdf.json`. It is a draft
because the canonical spec URL and the validator's current release are still to be fixed.
